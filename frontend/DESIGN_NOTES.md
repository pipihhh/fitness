# ezgym 展示站 · 设计系统说明（DESIGN_NOTES）

> 纯静态展示站（毕业设计 · 非商用）。落地页 `index.html` + 交互式 API 文档 `api.html`。
> 零构建、零 npm、零第三方 JS/图标库。所有图标为手绘 inline SVG。

---

## 0. 主题推导：为什么长这样

命题是 **「健身 / 力量 / 能量 × 工程精确性」**。
我没有从"运动 App 常见的活力橙渐变"出发，而是从这两个词的**交集**推导：

- 健身房里真正代表"力量 × 精确"的物件，是**测力器械上的刻度**——杠铃片的配重标、
  跑步机的心率/卡路里读数、力量台的负荷刻度尺。它们冷静、精密、可被读数。
- 后端工程里代表"精确"的，是**仪表化的读数**：请求→响应、依赖方向、测试计数。

两者合流成一个统一隐喻：**这个站点是一台"测力仪表台"（instrument panel）**。
课程模型里真实存在的 `burning`（消耗卡路里）字段被借用为主视觉——热量 = 燃烧 = 暖色点火。
于是配色从"燃烧"这一**真实领域字段**推导出点火暖色，而非套用现成活力橙。

这样做刻意避开了 AI 默认三件套：
- 不是 (a) 米白底 + 高对比衬线 + 陶土色；
- 不是 (b) 近黑底 + 单一荧光绿/朱红——我们用**双强调色**（点火橙 + 柠檬伏特绿），
  且强调色只用在签名刻度与关键读数上，其余安静；
- 不是 (c) 报纸式细线分栏——我们用**刻度尺 / 仪表卡片**作为结构语言。

## 1. Color —— 6 个命名 token（冷钢底 × 燃烧暖强调）

| token | hex | 角色 |
|---|---|---|
| `--graphite` | `#13171E` | 页面底色，冷钢石墨，偏蓝而非纯黑（区别于近黑荧光套路）|
| `--steel`    | `#1C232E` | 抬升面板 / 卡片底，仪表面板质感 |
| `--chalk`    | `#EAEEF3` | 主文字，冷白（粉笔标线感）|
| `--ember`    | `#FF6A2C` | **签名强调 1**：点火橙，源自 `burning` 卡路里字段；POST/能量/刻度指针 |
| `--volt`     | `#D6F24B` | **签名强调 2**：柠檬伏特绿，数据读数 / GET / 命中高亮（黄绿而非纯荧光绿）|
| `--dim`      | `#7B8698` | 眉标、编号、次要说明、刻度线 |

辅助：`--hairline rgba(235,238,243,.12)`（发丝分隔线）、方法徽章语义色
GET=volt / POST=ember / PUT=琥珀 `#F2B84B` / DELETE=`#FF5470`。

## 2. Type —— 三种角色，刻意搭配

| 角色 | 字体 | 用法 |
|---|---|---|
| display | **Oswald**（凝缩工业无衬线，回退 `Archivo Narrow`/系统 condensed）| 大标题一律**大写 + 加宽字距**，像体育场 / 器械丝网印刷标牌，承载"力量"个性 |
| body | **Inter**（中性几何无衬线，回退系统栈）| 正文、说明，工程感、克制易读；中文回退 `PingFang SC`/`Microsoft YaHei` |
| mono | **JetBrains Mono** | 所有"仪表读数"：编号、端点路径、JSON、计数、刻度数字 |

字号阶梯（rem）：display `clamp(2.6,6vw,5.2)` / h2 `clamp(1.8,3vw,2.6)` /
h3 `1.15` / body `1rem` / small `.82` / mono-tick `.7`。
字重：Oswald 500/600/700，Inter 400/500/600，JetBrains 400/500。

## 3. Layout —— 仪表台 + 左侧刻度轨

- 内容最大宽 `1180px` 居中，两侧留白。
- 每个大区块左缘有一条**编号刻度轨**（section rail）：`01 / 02 / 03…` + 竖向眉标 +
  一列 tick 短线。编号即真实信息（领域顺序、层级深度、流程序号），不是装饰。
- 卡片 = "仪表面板"：`--steel` 底、发丝边、四角有小刻度角标（corner ticks）。
- 12 列意识的响应式：桌面多列网格 → 移动端单列；刻度轨在窄屏折叠为顶部小眉标。

## 4. Signature —— 「测力刻度尺 / 仪表读数」

被记住的唯一签名元素是**贯穿全站的校准刻度尺（calibrated scale）**：
1. Hero 里一条水平 **BURN GAUGE**（燃烧刻度条）：等距 tick + 数字刻度 + 点火橙指针，
   底下配一段"活的" API 读数（真实 `GET /api/courses` 请求→响应），像器械显示屏。
2. 每个 section 的分隔用**同一套 tick 刻度语言**，而非普通细线。
3. 架构图用刻度语言编码"依赖深度"：层越深、tick 越密，箭头单向向下 = 编译期依赖方向。
4. API 文档页的方法徽章、锚点导航、命中计数，都复用刻度 / 读数视觉。

一句话：**大胆全部集中在"刻度尺"这一个母题上，其余克制安静。**

## 5. 可访问性 & 动效

- 响应式至移动端（≥320px 可用）。
- 键盘焦点：`:focus-visible` 用 `--volt` 2px 外描边，处处可见。
- `prefers-reduced-motion: reduce`：关闭指针脉冲、扫描线、滚动出现动画，只留静态。
- 语义标签（header/nav/main/section/article/footer）、SVG `aria-hidden` 或 `role/aria-label`、
  可交互控件有 `aria-*`、图片/图标有替代文本。
