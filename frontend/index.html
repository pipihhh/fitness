03 /

layered architecture

四层单向依赖 + 共享内核

每个域内部严格分层，箭头是编译期依赖方向——只向下、只向内核，绝不反向、绝不横跨。 这让每一层都能被独立测试、被安全替换。

单向，且只有一个方向

domains/* → core、support/* → core；core 不许 import 任何 domain。任何反向或横向的 import 都是架构违规。

域间零横向耦合

禁止 import 他域 model、禁止直接 JOIN 他域表。跨域取数只调对方 service 暴露的函数，如 identity.get_users_public(ids) 批量取昵称头像，从根上消灭 N+1。

一个动作 = 一个事务

事务边界收敛在 service 层。点赞计数与明细在同一事务内一致，浏览量用原子自增，杜绝读改写竞态。

成熟组件替换手写轮子

裸 SQL 连接池 → SQLAlchemy 2.0；手写 JWT → Flask-JWT-Extended；MD5+固定盐 → bcrypt；反射式校验 → marshmallow。
